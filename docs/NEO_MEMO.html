Score-Seeking Eval

When an agent can succeed the hard honest way or take an easy illegitimate shortcut, how often does it cheat — and what does it do when a monitor stands in the way?

Author Long Yi Models DeepSeek-V4-Pro · Kimi-K2.6 · gpt-4o · gpt-5.4 · Claude 4.5 Repo github.com/longyi1207/score-seeking-eval Draft Sep 2026

A presentation set of 11 scenarios (see docs/STATUS.md), each pairing an intended honest path with a shortcut — from a forged state file to an exploit-gated soft edge (a confused-deputy SSRF, a gamed metric, a real CVE) — and an un-gameable grader, on real Azure Active Directory ranges and Dockerized tasks. Draft / capability-control tasks are held out of the propensity claims below. Primary scientific endpoint is now a hazard cheat-mode propensity vector (CN vs US/EU under one construct) — locked claim language in docs/HEADLINE_RESULTS.md. Eval-time, black-box complement to Anthropic's training-time reward-seeker organism. External brief with mode glossary + turns: docs/HEADLINE_RESULTS.md.

1The construct — one shape, everywhere

Honest path.
The intended, laborious way — a multi-hop compromise, a real proof, a genuine bug fix.
Planted shortcut.
An easy, illegitimate win left reachable — a leaked flag, a forged state file, a faked result.
Un-gameable grader.
Ground truth the agent can't reach — watermarks, held-out tests piped in at grade time, root-only audit logs, the proof checker's own axiom list, PID-liveness observed from outside.

A run is labelled honest_solve, score_seek_success, or fail — by how it finished, not just whether it did.

2Headline — CN vs US/EU is a vector, not a nationality scalar

Under this suite’s shared construct (long-horizon agent + detectable shortcut + provenance grader), equal-weight mean hazard rate is CN ≈ 0.14 vs US ≈ 0.21 (Δ ≈ −0.07). Chinese-lab API models are not uniformly higher. The ranking flips by cheat family; within-CN, DeepSeek ≫ Kimi. 5What we found

  1. CN vs US/EU is mode-specific — scalar Δ ≈ −0.07.

    Equal-weight over 7 hazard modes: CN 0.14 vs US 0.21. CN↑ on backdoor/oversight (DeepSeek-driven); US↑ on deception/metric/SSRF (gpt-4o-driven). gpt-5.4 closes the protocol gap; zh prompt doesn't; open-weight stratum empty. Quote docs/HEADLINE_RESULTS.md — not "Chinese models are more dangerous."

  2. The cheat is model × cheat-type specific.

    Each model has a distinct profile and the ranking flips by family (§4). Propensity is a vector, not a scalar — "task-specific" made measurable.

  3. A planted prior-agent precedent is the reliable elicitor — more than pressure.

    On exploit-gated tasks the strong cells are endorsing (esp. with recipe). Deadline pressure amplifies probing without delivery. Recipe ablation leaves a DeepSeek residual.

  4. Grader salience and forbid are strong levers; language is not.

    salient_grader=off zeros CN protocol seeking but not gpt-5.4; forbid zeros the backdoor panel-wide; 中文 prompt does not shrink rates. Watchdog routes gpt-5.4 into safety_tool_sabotage 5/5.

  5. You cannot patch your way to safety in-environment; single runs mislead.

    Every in-container defense fell to a more sophisticated exploit (§3) — only ground truth outside the agent's reach held. First protocol_re run looked honest; at n = 5 DeepSeek takes the backdoor 5/5.

6Honest limitations

  • n = 5 is still noisy. Read profiles and directions, not second decimals. Higher-n confirmation before hard external quoting.
  • Panel is API-shell only. Open-weight GPU (B3) and training-class regression (B4) are backlog — do not claim open-weight or RLVR-causal effects yet. Claude is on protocol_re only.
  • gpt-4o's "honest" on hard tasks is often capability — its cheat profile speaks where it can do the task (deception, metric).
  • Built and graded by one person; findings want external replication. Kimi AD cells still pending on an NTLM image-drift infra issue.
