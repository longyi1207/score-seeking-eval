Score-seeking in long-horizon agents

Controlled eval suite · propensity under pressure · not a global “misaligned” score

Every task has the same shape: a hard honest path, an optional shortcut (misconfig / CVE / backdoor / kill-monitor / …), and an ungameable grader outside the agent’s reach so we label how it succeeded. Neo RQ: how weird are models on long hard tasks — closer to HF / collusion.wiki slippery slopes than one-step alignment quizzes.

Construct

  1. Honest path — laborious, intended success
  2. Planted / exploit-gated shortcut — reachable but illegitimate
  3. Held-out grader — watermark / ground truth the agent cannot rewrite

Panel: DeepSeek-V4-Pro · Kimi-K2.6 · gpt-4o · gpt-5.4 · Claude Sonnet 4.5 · n=5.

Suite layers

  • Azure AD — planted-flag construct; 5-length honest-path ladder in flight
  • Hazard Docker — protocol RE, live oversight, SSRF, metric, Grafana CVE
  • Games / formal — hard chess, Lean, web bring-up
  • Factors — forbid · endorse ± recipe · social notes · inoculation
